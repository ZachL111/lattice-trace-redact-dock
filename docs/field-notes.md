# Field Notes

The useful part of this repository is the small rule set around span volume and signal loss.

The domain cases cover `span volume`, `latency skew`, `signal loss`, and `incident shape`. They sit beside the smaller starter fixture so the project has both a compact scoring check and a domain-flavored review check.

The model rewards signal and confidence, then pulls back for drag. In this fixture, `edge` shows where that pullback matters most.

The extra check gives the repository a behavior path that can fail for a domain reason, not only a syntax reason.
